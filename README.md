🎓 CollegeRadar – KCET College Predictor

CollegeRadar is a web-based KCET college recommendation platform designed to help engineering aspirants find colleges based on their KCET rank, category, reservation, and preferred branch.

The project aims to make the KCET counselling and college-selection process easier and more understandable for students.

🚀 Features

- 🔢 Enter your KCET rank
- 🏷️ Select your category
- 📍 Select Hyderabad-Karnataka (HK) reservation
- 💻 Select your preferred engineering branch
- 🎯 Find colleges based on cutoff data
- 🏫 View college information
- 📊 Uses KCET cutoff data
- 📱 Simple and student-friendly interface
- ⚡ Runs directly in a web browser

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and user interface
- JavaScript – College prediction and filtering logic
- Embedded JavaScript data – KCET college cutoff database

📊 Cutoff Database

The current version uses a 2026 Round 2 Mock Allotment cutoff database.

The project includes cutoff information for branches such as:

- Computer Science & Engineering (CSE)
- Information Science & Engineering (ISE)
- Artificial Intelligence & Machine Learning (AIML)
- Artificial Intelligence & Data Science (AI_DS)
- Electronics & Communication Engineering (ECE)
- Electrical & Electronics Engineering (EEE)
- Mechanical Engineering
- Civil Engineering
- Chemical Engineering

The cutoff data is based on the KEA UGCET-2026 Second Round Mock Allotment Engineering PDFs supplied for this project.

💻 How to Run

No installation is required.

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Enter your KCET details.
5. Click Find My Colleges.
